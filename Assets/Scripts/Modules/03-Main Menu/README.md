## Update Properties
- در طول هر ثانیه یک درامد ثابت نمایش میدهد
- درامد بدست آمده تا لحظه برداشت یک ماکزیموم دارد
- آپدیت هر طبقه خانه چند بخش دارد
  - (20 لول آپدیت) ماکزیموم جمع آوری امتیاز
  - (20 لول آپدیت)سرعت جمع آوری در ثانیه
  - افزایش یک طبقه جدید
- طبقات میتواند در آینده قابلیتهای مختلفی را داشته باشند

> [!NOTE]  
>  خریداری خانه و درامد ثابت خانه در منوی اصلی
